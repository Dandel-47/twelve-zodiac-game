# twelve-zodiac-game
话不多说，下面直接介绍游戏规则！

游戏名：十二生肖 

这是一款1v1游戏，目前这是在电脑上和AI对战的版本 

两种游戏玩法

第一种玩法： 

初始阶段，双方都是“鼠”，单个整局获胜后可升一级（如“鼠”升级为“牛”、“龙”升级为“蛇”），败方不升级 单个整局中有若干个回合，每个回合双方进行剪刀石头布，胜者可进行一次行动（即进入自己的回合），行动内容只能选择“普通攻击”、“回血”、“特殊招式”中的一种。 

下面介绍每种动物的能力 
共有能力：
1.每种动物都有初始血量10点，且血量上限是10
2.普通攻击伤害1点、给自己回血1点 各自的特殊能力（包括”特殊招式“和”被动技能“） 

补充说明： 1.每回合的所有伤害，都会在回合结束时统一生效 
2.“马”和“羊”的的普通攻击伤害为1.5，初始血量和血量上限为12 
3.”猴“”鸡“”狗“”猪“的初始血量和血量上限为15 
4.特殊招式无冷却时间，但可能有使用次数限制（未说明则没有次数限制） 
5.剪刀石头布若平局，则该回合作废（即：无视它，不把它当作是一个回合），直接进入下一回合 
6.等级补偿机制：若一方的等级比另一方高，则弱势方可获得初始血量和血量上限的补偿，具体规则为：双方等级差1级，弱势方初始血量和血量上限在原基础上再加3点；若等级差距≥2级，则在差1级的基础上，每多差1级，弱势方的初始血量和血量上限就再加2点（例如：鼠打牛，则鼠获得3点生命值补偿；马打猴，则马获得5点生命值补偿，羊打狗，则羊获得7点生命值补偿，以此类推） 


1.鼠： 
特殊招式：无 
被动技能：【饕餮】无血量上限的限制 （特殊规则：在”鼠“与”鼠“的对战中，双方的被动技能会同时失效） 

2.牛： 
特殊招式：【上吊】对敌方造成0.5点伤害，并使对方处于”上吊“状态。处于”上吊“状态的敌人无法进行任何攻击行为（即无法做出任何造成伤害的行为），对方可在自己的回合选择”下吊“（且此回合无法再做其他行动）以解除”上吊“状态 
被动技能：无

3.虎： 
特殊招式：无 
被动技能：【虎威】若”虎“玩家在剪刀石头布中取得连胜（平局不中断连胜），则普通攻击伤害逐次提升。第一次为正常伤害1点，若连胜两回合，则第二次伤害为2点，第三次则同理，伤害为3点，但若连胜三回合以上，则普攻伤害仍为3（3是上限）。若连胜中断，则普攻伤害重回常态的1点 

4.兔 
特殊招式：【闪避】该技能有三次使用机会，且该技能不仅可以在自身回合使用，还可以在对方回合使用。使用该技能后，立刻进行一次判定，即与对手剪刀石头布（若平局则不算，再来一次），若胜利，则免疫此回合受到的所有伤害。 该技能还有一种特殊使用方法：可消耗两次使用机会，获得一次【极限闪避】，效果为跳过判断环节，直接获得一回合的免伤效果 
被动技能：无 

5.龙 
特殊招式：【腾飞】回复0.5点血量，并进入“滞空”状态，该状态只能持续到下个回合（下个回合结束后自动结束“滞空”状态）。在“滞空”状态下被敌方造成总计任何数值的伤害，都只会生效为“受到1点伤害”（若本来敌方造成伤害就≤1点，则该回合不受伤害），并立刻结束“滞空”状态。 
被动技能：【俯冲】在“滞空”状态下受到伤害，可选择扣除自身1点血量，使对方受到同样数值的伤害（即“反伤”效果） 

6.蛇 
特殊招式：【放毒】给对方挂上一层“毒印记”，该印记从下一回合开始生效，印记最多叠加两层。敌方身上每有一层“毒印记”，就会在一回合内失去1点血量。敌方可在自己的回合选择“解除”一层“毒印记”（且此回合无法再做其他行动）。在敌方身上有“毒印记”时，还可以释放【引爆】（只能使用一次），效果为：敌方身上每有一层印记，就对其造成2点伤害，然后清除敌方身上所有印记。 
被动技能：【搏命】“蛇”的生命上限只有9点，且“蛇”可在一个整局开始前，选择进入【觉醒状态】（持续一整局），此状态下，“蛇”的“毒印记”可最多叠加三层，但生命上限只有6点

7.马 
特殊招式：【旋踢】造成1点伤害，并获得20%吸血效果（即，给自身回复一定量的血量，其值为对方此时血量值的20%，小数不满0.5则进位到最近的0.5处，如：1.25进位为1.5、2.875进位为3） 
被动技能：【重伤】”马“对敌方造成的所有伤害，都会附加扣除敌方等量的血量上限的效果（但优先级低于【饕餮】） 

8.羊 
特殊招式：【占卜】该技能有3次使用机会，且可在任意时刻使用。玩家需预判下一回合的剪刀石头布结果（对玩家自己而言，有”赢“”输“”平“三种情况），若预测成功，则在该回合获得不同的收益：预测“赢”成功，则对敌方造成【延迟伤害】，即在下一回合自动对敌方造成2点伤害（无论是不是自己的回合，因为“自动”意味着不消耗“行动”次数）；预测“输”成功，则立即回复1.5点血量，并“操控”对方进行行动（代替对面决策该回合干什么）；预测“平”成功，则立即回复1点血量，并获得一个给自己行动的额外回合 
被动技能：【幸运】每预测成功一次，则增加一次【占卜】的使用机会


9.猴
特殊招式：【暴击】使敌方的血量变为原来的一半（敌方血量除以二后若有小数，则退位到最近的0.5处，如：1.25退位为1、2.75退位为2.5）
被动技能：【三相】“猴“拥有三种形态，切换形态算作一次行动（即此回合无法再做其他行动）。①【平静形态】该形态为对局开始时的初始形态，该形态下普通攻击伤害为1点，并附带回复1点血量的效果；从【愤怒形态】切换为该形态时，自身立即回复4点血量；该形态下无法使用特殊招式；②【愤怒形态】该形态下普通攻击伤害为2点，但自身受到的伤害变为原来的两倍；③【神格形态】进入该形态后无法切换至其他形态，且进入两回合倒计时（从下回合开始计，剪刀石头布的平局不算回合），两回合结束后若此局仍未分出胜负，则”猴“立刻死亡，输掉该局。在这两回合中，”猴“获得50%减伤（即受到的伤害变为原来的一半，若有小数则退位到最近的0.5处，规则同上），且无法进行普通攻击，但同时特殊招式变为【斩杀】，【斩杀】只能在敌方血量≤4时使用，效果为直接击杀对面，获得胜利（其优先级高于一切”免伤“或”减伤“技能，但低于”鸡“的【司命】中的瞬时无敌效果）

10.鸡
特殊招式：【延生】该技能只能在”濒死“状态下使用（立刻释放）。鸡在被对方杀死后，不会直接输掉该局，而是进入”濒死“状态，在此状态下，鸡可再继续一回合，若成功使用【治疗】，则退出”濒死“状态并获得1点生命值，否则输掉该局
被动技能：【司命】在”鸡“死亡当局自动触发（即【延生】使用失败或故意不使用【延生】时触发），”鸡“立刻恢复至死亡前的血量，此效果只能触发一次。在触发【司命】后，下两个回合”鸡“将获得100%免伤效果，且普攻伤害变为2.5点


11.狗
特殊招式：【审判】该技能有三次使用机会，且只能在某回合开始前使用（立即释放），该回合内敌方的一切”特殊招式“和”被动技能“带来的除基础伤害之外的增益效果都失效（”蛇“的”毒印记“造成的伤害不算作基础伤害），该技能优先级高于一切（若双方都为”狗“则该技能可互相抵消）
被动技能：【回溯】剪刀石头布每遇到三次平局，可触发一次（也可人为选择不触发），效果为直接回到满血状态。该效果一局只能触发一次。

12.猪
特殊招式：【压迫】该技能有两次使用机会，对敌方造成5点伤害，且附带下面三种效果之一：①该伤害无视”免伤“效果；②若下一回合是敌方回合，则其只能使用普通攻击；③将技能伤害降为1点，但获得一个数值为3的护盾（护盾可抵挡伤害，且其数值可叠加，若某回合敌方造成伤害超过护盾当前数值，则”猪“不会受到溢出的伤害）
被动技能：【勇毅】在血量初次低于6时，立刻获得一个数值为2的护盾，在血量初次低于3时，立刻获得一个数值为1的护盾（护盾皆从下一回合开始生效）；血量低于5时，”猪“的普攻伤害为2点


第二种玩法：

12个生肖分别作为12个角色供玩家选择
双方先进行一次剪刀石头布，胜者先选角色，然后轮流选完，每方6名角色
然后开始bp环节
先进行两次剪刀石头布，每次的胜者可以禁用掉对方6名角色中的1名
接着开始给角色排出场顺序，即从己方阵营中未被禁用的角色中选角色上场，规则为：双方先进行一次剪刀石头布，胜者为红方，败者为蓝方；接下来顺序为：红方先选一名角色，然后蓝方选两名，然后红方再选两名，然后蓝方再选两名，然后红方再选一名。每方可派四位角色上场

双方排序第一的角色率先交战，交战时若一方的某个角色阵亡，则下一名立刻替补，继续战斗，直至一方四名角色全部阵亡，则另一方获得胜利

附：“鼠”由于太弱势，在此玩法中，鼠的【恢复】技能从回复一点血量变为回复两点血量
